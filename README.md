# Portfolio Personal

Portfolio web desarrollado con Next.js (frontend) y Django (backend), con soporte multiidioma (Español, Inglés, Catalán).

## 🚀 Tecnologías

### Frontend
- **Next.js 15** - Framework React
- **TypeScript** - Tipado estático
- **CSS** - Estilos personalizados con paleta Sorbus
- **React Icons** - Iconos

### Backend
- **Django** - Framework Python
- **PostgreSQL** - Base de datos
- **Django REST Framework** - API REST

### DevOps
- **Docker** - Contenedorización
- **Docker Compose** - Orquestación de contenedores

## 📁 Estructura del Proyecto

```
Porfolio/
├── frontend/          # Aplicación Next.js
├── backend/           # API Django
├── docker-compose.yml # Configuración Docker
└── README.md
```

## 🛠️ Instalación y Uso

### Prerequisitos
- Docker
- Docker Compose

### Ejecutar el proyecto

```bash
# Clonar el repositorio
git clone git@github.com:NorbertAguilera/Porfoleo.git
cd Porfoleo

# Iniciar los contenedores
docker compose up

# Acceder a la aplicación
# Frontend: http://localhost:3000
# Backend: http://localhost:8000
```
